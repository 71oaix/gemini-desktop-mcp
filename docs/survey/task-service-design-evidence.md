# Gemini 页面现状与设计证据

页面调查：2026-11-16；源码与真实运行复核：2026-11-17；实时能力目录与状态表达复核：2026-11-18。对象为已登录的 1.16.0 客户端及当前在线页面；模型清单随页面变化，本文不是程序固定枚举。

## 已核对的页面事实

页面调查先通过窗口观察确认菜单外观，再通过现有 `inspect_settings` 只读探针复核 DOM。模型与思考菜单使用受限 `settings_action` 展开和收起；该路径检查页面无草稿、无生成占用，不使用窗口焦点、键鼠或截图坐标。调查未发送真实消息，未改模型、模式或思考等级，结束时菜单已收起，仍为 Hydrogen。

| 页面条目 | 用途文字 | DOM 观察 | 可用性结论 |
|---|---|---|---|
| 3.5 Flash-Lite | 快速解答 | `menuitemradio`，可见 | 已通过动态名称选择完成真实文本任务 |
| 4 Hydrogen | 日常帮助 | `menuitemradio`，当前勾选 | 默认模型；已实测三任务同时生成并完整完成 |
| 3.1 Pro | 深度研究 | `menuitemradio`，可见 | 菜单中存在，未实测发送 |
| 4 Argon | 代码与分析 | `menuitemradio`，可见 | 菜单中存在，未实测发送 |
| 4 Carbon | 高难任务 | 可见、有锁图标；条目标识含 `upsell`，但 `disabled=false` | 受限/升级入口证据，不能当成已可用模型 |

该菜单中没有 3.8 Flash。不能把此结论扩大为所有账号、地区、版本或以后时间的固定名单。

模型条目由共同的 `bard-mode-option-` 前缀识别，后缀存在不透明值；不能因一次观察就承诺其跨版本稳定。思考子菜单实测包含“低 Fast and efficient”“中 深度适中”“高 超级详尽”。页面操作可以选中低，但正式契约是：对话模式使用并核实高思考，任务模式没有思考等级入口时报告 `not_exposed`，不伪造等级。

## 已实现的页面接入与完成判定

当前离线回归通过，并已用新 MCP 服务实测三条独立对话同时生成、全部完整完成并释放占用。详细范围见[验证状态](../../ACCEPTANCE.md)。

| 机制 | 当前源码行为 | 证据 |
|---|---|---|
| 准备期页面独占 | 从准备开始保持独占页面，不能静默转交；准备任务也占用现有上限名额 | 门控并发回归，第四个准备任务被限流 |
| 页面申请失败清理 | 申请与绑定处于统一失败/清理范围，额外资源绑定失败会关闭；空白页首次加载后等待握手 | factory、加载失败、延迟与超时回归；真实握手超时后占用归零 |
| 动态模型选择 | 接受有界字符串，按实页完整条目标识或唯一名称选择；重新核对勾选；等待异步加载的目标选项 | 生产名单外的新名称、完整标识、歧义、锁定与异步菜单回归 |
| 无自动替代与补做 | 默认统一 Hydrogen，取消发送前替代、模式保底切换及完成后额外发送 | 严格失败及不创建补做回归；旧结果链接只读兼容 |
| 模式就绪与恢复页 | 新独立任务避开模式未知的恢复页面，在新入口等待明确模式推送后再核实设置 | 迟到控件和未知恢复页回归；真实三任务均核实为对话模式 |
| 完成判定 | 唯一任务标记、严格配对的完整未截断回答、无生成迹象及两秒稳定；原生通知仅在已核实对话模式作为组合证据 | 页面完成控件路径与原生通知组合路径均有实测 |
| 原生通知绑定 | 在隔离 preload 的原厂 send 调用处捕获开始上下文，结束沿用相应上下文；严格校验文档、绑定代次、任务和顺序 | 旧绑定、旧任务和乱序反例被拒绝；实际客户端挂钩生效 |
| 异常清理 | 并行 fencing 时收束全部在途监听、定时器和任务后再释放执行权、关闭数据库 | 修前失败已复现，修后退出前完成清理 |
| 数据库初始化 | 先启用有界锁等待，再设置 WAL；表结构变更和 schema 标记原子提交 | 多进程同步初始化与旧库锁反例 |

旧别名表仅用于兼容已有请求/结果，不再限定可选模型，也不作为实时可用清单。Carbon 的锁/upsell 与 `disabled=false` 差异仍属于需要表达的页面事实。

实测发现恢复的主页面可能处于已有会话且没有模式控件；新入口的输入框也可能早于模式控件挂载。新独立任务现避开模式未知的恢复页面，在新入口等待明确模式推送后再核实设置。离线回归覆盖迟到控件和未知恢复页，真实三任务均核实为对话模式。

隐藏额外页面可以有正确回答和匹配原生结束通知，却没有可用于完成判定的复制按钮。现对已核实的对话模式允许严格组合证据：唯一任务标记、严格配对的完整未截断回答、确认会话、唯一有序且同任务同会话的原生 start/complete、无生成迹象及两秒稳定。原生通知不能单独完成，任务和未知模式仍要求页面控件；复制按钮未出现的前端成因不据此作额外推断。

原厂客户端会将普通子窗口的 Gemini 导航当作登录弹窗回流，关闭子窗口并导航主页面；实际日志曾与两个失败任务对应。额外 Gemini 页面现放在嵌入式 WebContentsView 中，宿主窗口保持空白，未修改原厂导航规则；采用该结构后未再观察到回流。额外视图的后续握手失败已定位为配置复制遗漏预加载脚本：Electron 44.5.1 的 `getLastWebPreferences` 返回的有限字典不含 preload，原测试人为加入该字段。现由补丁启动代码相对包内位置解析 `src/preload.js` 并显式传入，缺失或不可用时在创建页面前失败；真实最小测试已验证额外页面连接与收发。依据为 [Electron 44.5.1 配置快照实现](https://github.com/electron/electron/blob/v44.5.1/shell/browser/web_contents_preferences.cc#L363-L383)，以及正式回归与两任务实测。

## 当前会话承载与后台结构

以下由当前源码核对，不等同于真实资源压力测试。

| 事实 | 依据 | 结论与限制 |
|---|---|---|
| 优先匹配目标会话页面；新独立任务仅复用模式可识别的空闲主页面，否则新建隐藏宿主窗口与嵌入 WebContentsView | [桌面桥](../../desktop-bridge.cjs) 的 `attachSession`、`openExtraSession`、`defaultCreateConversationView` | 不是为每个历史会话永久保留页面；额外页面共享原登录 session，但各有网页运行成本 |
| 正常任务清理会销毁额外网页视图及宿主窗口，保留主页面 | 同文件 `cleanupTask`、`closeSessionIfUnused` | 正常路径资源随活动并发增长；异常创建、退出和长期运行是否泄漏仍需验证 |
| 隐藏页面关闭后台节流，以持续观察生成 | 同文件 `defaultCreateConversationView` | 隐藏不等于不占 CPU/内存，不能用不可见证明资源可忽略 |
| 当前生成上限为 3，同一会话已有生成时拒绝第二轮 | 同文件 `MAX_GENERATING`、`conversationBusy`；[相关测试](../../tests/desktop-bridge.test.cjs) | 代码和模拟测试支持该策略；单页/多页的真实增量开销尚未测定 |
| 续聊入口要求本地父任务已完成并保存会话 URL | [队列](../../store.cjs) | 当前可续接本服务任务，尚不能管理全部 Gemini 历史 |
| 续聊时保留当前模式，冲突参数按策略处理 | [模式策略](../../desktop-model-policy.cjs) 的 `planSurfaceAction` | 会话中途不切模式；冲突请求的报告方式由接口契约约束 |
| 多轮依赖可通过父任务续聊关联；没有独立的多步业务任务管理实体 | [队列](../../store.cjs)、[工具契约](../../server.cjs) | 不将“一轮 completed”直接解释为整个业务任务结束 |
| supervisor 监督 worker，worker 持久化任务并连接桌面桥，观察器接收页面状态 | [监督进程](../../supervisor.cjs)、[后台执行](../../worker.cjs)、[桌面桥](../../desktop-bridge.cjs) | 需要分别判断进程存活、心跳、桥连通、页面可用和任务有无进展 |

现有核对只读取进程资源快照，没有建立不同并发度的对照，因此不报告单会话资源成本，也不以当前总进程内存判断页面策略是否合适。

## 未验证与证据边界

- 模型实际发送可用性与平台实际推理模型的可核实范围尚未逐项验证，不能从菜单存在直接推断。
- 隐藏页面完成控件缺失的前端成因尚未单独证明；严格组合证据只解决已核实对话模式的完成判定。
- 不同并发度的页面资源增量、异常创建和长期运行是否泄漏尚未测定。
- 最小化、真实网络故障、生成中客户端强制退出、执行进程或桥接任意崩溃组合尚未完整验收。
- 附件菜单、上传状态与移除、侧栏收起和窗口尺寸变化等页面状态尚缺对照。

结构调查优先只读；实测使用独立测试对话和明确测试材料，不覆盖用户草稿，不触发付费升级。全部历史会话管理不在当前范围，侧栏可见条目不构成完整历史清单或可用接口的证明。

## 设计边界

默认 Hydrogen 与动态发现分离；调用方可以获取实时选项并自主指定。结构标识与可见名称都作为证据，不能假设名称、标识后缀和顺序永久稳定。菜单未打开、采样失败、受限和确实不可用应分别表达。
